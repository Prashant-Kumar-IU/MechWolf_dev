# Templates

This directory contains template notebooks and configuration files for common MechWolf setups.

## Notebook Templates

- **2Syringes1RCoil1Mixer.ipynb** - Basic two-reagent synthesis setup
- **3Syringes1RCoil1Mixer.ipynb** - Three-reagent synthesis with single reactor
- **3Syringes2RCoil2Mixer.ipynb** - Complex multi-stage synthesis setup
- **nSyringesToRxnMixVessel.ipynb** - Scalable multi-syringe configuration
- **pump_calibration.ipynb** - FreeStep pump calibration guide
- **pump_code_generator.ipynb** - Automated pump configuration generator

## Configuration Files

- **apparatus_config.json** - Standard apparatus configuration template

## Usage

1. Copy the template that best matches your experimental setup
2. Modify the component specifications for your hardware
3. Update the protocol parameters for your specific synthesis
4. Run the notebook to execute your experiment

For detailed instructions, see the [Getting Started Guide](../docs/guide/getting_started.md).
