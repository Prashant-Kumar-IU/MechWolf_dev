# Examples

This directory contains example notebooks demonstrating MechWolf capabilities.

## Available Examples

- **peptide_synthesizer.ipynb** - Automated peptide synthesis workflow
- **peptide_synthesizer2.ipynb** - Advanced peptide synthesis with optimization
- **penetratin_synthesis.ipynb** - Cell-penetrating peptide synthesis example
- **sensor_test.ipynb** - Sensor integration and monitoring example

## Running Examples

1. Ensure MechWolf is installed: `pip install mechwolf`
2. Install Jupyter: `pip install jupyter`
3. Start Jupyter: `jupyter notebook`
4. Navigate to this directory and open any example notebook

## Hardware Requirements

Each example includes a hardware requirements section. Most examples can be run in simulation mode without physical hardware for learning purposes.

For detailed setup instructions, see the [Installation Guide](../docs/guide/installation.md).
